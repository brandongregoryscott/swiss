## `swiss audio classify DIRECTORY`

Listen to samples and assign categories before renaming them together.

```
USAGE
  $ swiss audio classify DIRECTORY [--autoplay] [--categories <value>]

ARGUMENTS
  DIRECTORY  Directory of samples to classify (not recursive)

FLAGS
  --autoplay            Play samples automatically when navigating; A toggles this during classification
  --categories=<value>  [default: one-shot,texture,noise,phrase,fx] Comma-separated categories, in cycling order

DESCRIPTION
  Listen to samples and assign categories before renaming them together.

  Up/down selects a sample, left/right cycles its category, and Space plays or stops it. A toggles autoplay: the
  selected sample plays immediately and each time you move up/down. --autoplay starts with it enabled. Each sample shows
  its duration. Unclassified samples keep their names. Enter reviews the renames; you can return to editing before
  applying them. Escape cancels without changing files.

  Names become "one-shot 1.wav", "one-shot 2.wav", etc., keeping their extensions and avoiding existing names. Only
  regular audio files directly in the directory are included. Requires ffprobe for durations, and afplay on macOS or
  ffplay elsewhere for playback. Audio is never re-encoded.

EXAMPLES
  $ swiss audio classify "/Users/Brandon/Music/Samples/Misc/Tascam Dumps/2026-11-02"

  $ swiss audio classify ./samples --categories "one-shot,texture,noise,phrase,fx,loop"
```

## `swiss audio:mp3 FILE... [-b BITRATE] [-y]`

Convert audio files, like WAVs, to MP3.

```
USAGE
  $ swiss audio mp3 FILE... [-b BITRATE] [-y]

FLAGS
  -b, --bitrate=<value>  Constant bitrate, like 320k, instead of V0 VBR
  -y, --yes              Overwrite files that are already there without asking, which is required when there's no
                         terminal to ask in

DESCRIPTION
  Convert audio files, like WAVs, to MP3.

  song.wav becomes song.mp3, at LAME's best variable bitrate setting (V0, around 245 kbps) unless you pick a bitrate.
  Files that are already MP3s are skipped.

  New files are written next to the ones they're made from, which are never changed. If one is already there, you're
  asked before it's overwritten; --yes overwrites without asking.

EXAMPLES
  $ swiss audio mp3 song.wav

  Convert every WAV here at a constant 320 kbps

    $ swiss audio mp3 *.wav --bitrate 320k
```

## `swiss audio:normalize FILE... [-t LUFS | -p] [-c DBTP] [-y]`

Make audio files a consistent loudness.

```
USAGE
  $ swiss audio normalize FILE... [-t LUFS | -p] [-c DBTP] [-y]

FLAGS
  -c, --ceiling=<value>  [default: -1] Highest true peak to allow, in dBTP, and the level --peak brings peaks to
  -p, --peak             Bring each file's loudest peak to the ceiling, instead of its loudness to the target
  -t, --target=<value>   [default: -14] Loudness to bring each file to, in LUFS
  -y, --yes              Overwrite files that are already there without asking, which is required when there's no
                         terminal to ask in

DESCRIPTION
  Make audio files a consistent loudness.

  song.wav becomes song-normalized.wav, in the same format and at the same quality. By default each file is brought to
  -14 LUFS, the loudness streaming services play music at, measured the way they do (EBU R128). Pick another target with
  --target, like -16 for podcasts or -23 for broadcast. --peak instead turns each file up or down until its loudest peak
  is at the ceiling, which suits samples and sound effects, where loudness over the whole file means less.

  Each file only has its volume changed, by the same amount throughout, so nothing is compressed or limited. Its loudest
  true peak is kept at or below the ceiling, -1 dBTP unless you pick one, which leaves room for MP3 encoding not to
  clip. A quiet file with loud peaks may stop short of the target because of that, and you're told how loud it got.
  Files already within 0.1 dB are skipped.

  Levels are always 0 or below, so the minus sign is optional: --target 16 is -16 LUFS.

  New files are written next to the ones they're made from, which are never changed. If one is already there, you're
  asked before it's overwritten; --yes overwrites without asking.

EXAMPLES
  $ swiss audio normalize song.wav

  Bring every MP3 here to -16 LUFS

    $ swiss audio normalize *.mp3 --target -16

  Turn samples up until their peaks are at -1 dBTP

    $ swiss audio normalize kick.wav snare.wav --peak
```

## `swiss audio:stereo FILE... [-c left|right] [-y]`

Make mono audio stereo, by copying it onto both sides.

```
USAGE
  $ swiss audio stereo FILE... [-c left|right] [-y]

FLAGS
  -c, --channel=<option>  Side of a stereo file to copy onto both, rather than the one with sound on it
                          <options: left|right>
  -y, --yes               Overwrite files that are already there without asking, which is required when there's no
                          terminal to ask in

DESCRIPTION
  Make mono audio stereo, by copying it onto both sides.

  song.wav becomes song-stereo.wav, in the same format and at the same quality. Each side is the source exactly, so it's
  no quieter than the original.

  A file that's stereo but has sound on only one side, like a mono mic recorded on a stereo track, plays in one ear.
  These are found by comparing the sides' levels: when one is more than 20 dB quieter than the other, the louder side is
  copied onto both. A stereo file with sound on both sides is skipped, unless --channel picks a side to copy.

  New files are written next to the ones they're made from, which are never changed. If one is already there, you're
  asked before it's overwritten; --yes overwrites without asking.

EXAMPLES
  $ swiss audio stereo vocals.wav

  Copy the left side onto both, whatever's on the right

    $ swiss audio stereo take.wav --channel left
```

## `swiss audio:trim FILE_OR_DIRECTORY... [--threshold DB] [--silence SECONDS] [--padding SECONDS] [--no-review | --review-only]`

Trim silence from the beginning and end of audio samples, then compare them before replacing originals.

```
USAGE
  $ swiss audio trim FILE_OR_DIRECTORY... [--threshold DB] [--silence SECONDS] [--padding SECONDS] [--no-review
    | --review-only]

FLAGS
  --padding=<value>    [default: 0.01] Seconds of silence to retain at each trimmed edge
  --[no-]review        Compare originals and trimmed files interactively after trimming
  --review-only        Review existing original/trimmed pairs without creating files
  --silence=<value>    [default: 0.05] Minimum silence duration to detect, in seconds
  --threshold=<value>  [default: 60] Silence threshold in dB (minus sign optional)

DESCRIPTION
  Trim silence from the beginning and end of audio samples, then compare them before replacing originals.

  Accepts files or directories (not recursive). Writes sample-trimmed.wav beside sample.wav, keeping the format,
  channels and bit depth where supported. Lossy formats are re-encoded. Existing outputs are never overwritten. Files
  already ending in -trimmed are ignored. Interior pauses are preserved; entirely silent files and files without
  removable edge silence are skipped.

  Silence must be below --threshold (default -60 dB) for at least --silence seconds (default 0.05). --padding keeps 0.01
  seconds at each trimmed edge by default. A higher threshold trims more aggressively; use --threshold 50 for -50 dB.

  In a terminal, review successful trims: left plays the original, right plays the trimmed sample, Space plays/stops,
  and up/down moves between pairs. D marks an original for replacement; Enter shows the plan and asks for consent,
  starting on no. Confirming replaces each marked original with its trimmed audio, dropping the -trimmed suffix so the
  original filename is kept. Escape keeps both versions. Changed or missing files prevent replacement.

  --no-review only writes trimmed files; it is also the behavior without a terminal. --review-only reopens comparisons
  for existing original/trimmed pairs without trimming again.

EXAMPLES
  $ swiss audio trim kick.wav snare.wav

  $ swiss audio trim "./samples" --threshold 50 --padding 0.02

  $ swiss audio trim "./samples" --review-only
```

## `swiss autocomplete`

Set up tab completion for commands and flags in zsh.

```
USAGE
  $ swiss autocomplete [-r]

FLAGS
  -r, --refresh-cache  Only rebuild the completions, without changing ~/.zshrc

DESCRIPTION
  Set up tab completion for commands and flags in zsh.

  Builds the completion files, then adds a line to your ~/.zshrc that loads them. The line is only added once: running

```

## `swiss base64 decode [INPUT]`

Decode base64 to text, or to a file.

```
USAGE
  $ swiss base64 decode [INPUT] [-c]

ARGUMENTS
  [INPUT]  Base64 to decode [default: stdin if piped, otherwise the clipboard]

FLAGS
  -c, --copy  Also copy the result to the clipboard (text only)

DESCRIPTION
  Decode base64 to text, or to a file.

  The input is read from the argument, from stdin when it's piped in, or otherwise from the clipboard. The standard and
  URL-safe alphabets are both accepted, with or without padding, and whitespace is ignored so line-wrapped base64 works
  too.

  Decoded data that isn't text, like an image, is only written when stdout is redirected, so it doesn't garble the
  terminal. Redirected output is written byte for byte, with no newline added.

EXAMPLES
  $ swiss base64 decode aGVsbG8gd29ybGQ=

  Decode what's on the clipboard, and copy the result

    $ swiss base64 decode --copy

  Decode to a file

    $ swiss base64 decode < image.b64 > image.png
```

## `swiss clean [DIR]`

Delete dependency and build output directories, like node_modules and dist, anywhere under a directory.

```
USAGE
  $ swiss clean [DIR] [--dry-run] [-y]

ARGUMENTS
  [DIR]  [default: .] Directory to clean

FLAGS
  -y, --yes      Delete without asking first
      --dry-run  List what would be deleted without deleting anything

DESCRIPTION
  Delete dependency and build output directories, like node_modules and dist, anywhere under a directory.

  These directories are cleaned: .next, .nuxt, .parcel-cache, .svelte-kit, .turbo, build, coverage, dist, node_modules,

  --yes is required when there's no terminal to confirm in.

EXAMPLES
  $ swiss clean

  See what would be deleted across every project in ~/code

    $ swiss clean ~/code --dry-run

  Delete without asking

    $ swiss clean --yes
```

## `swiss cron [PATTERN]`

Explain a cron pattern in words, with how often it runs, and show when it runs next.

```
USAGE
  $ swiss cron [PATTERN...] [-n <value>] [--tz <value>]

ARGUMENTS
  [PATTERN...]  The cron pattern, quoted so the shell doesn't expand its * [default: stdin if piped, otherwise the
                clipboard]

FLAGS
  -n, --count=<value>  [default: 5] How many of the next runs to show
      --tz=<value>     IANA time zone the cron runs in, like Europe/London or UTC [default: the system zone]

DESCRIPTION
  Explain a cron pattern in words, with how often it runs, and show when it runs next.

  Patterns have 5 fields (minute, hour, day of the month, month and day of the week), or 6 with seconds first. Names
  like MON and JAN, ranges, steps, lists, L for the last day, 5#2 for the second Friday, and macros like @daily and
  @hourly all work.

  The run times are in the local time zone, or --tz, which should be the zone the cron runs in. Servers and most CI and
  cloud schedulers run cron in UTC.

  The pattern is read from the argument, from stdin when it's piped in, or otherwise from the clipboard.

  For common patterns to start from, use `swiss cron examples`.

EXAMPLES
  Explain a pattern

    $ swiss cron '*/15 9-17 * * 1-5'

  Show the next 3 runs of a UTC schedule

    $ swiss cron '0 2 * * *' --tz UTC -n 3

  Explain the pattern on the clipboard

    $ swiss cron
```

## `swiss date [INPUT]`

Show a date in every common format.

```
USAGE
  $ swiss date [INPUT...] [--tz <value>] [--unit s|ms|us|ns] [-c] [-f
    iso|iso-local|local|epoch|ms|relative]

ARGUMENTS
  [INPUT...]  [default: now] An epoch number (s, ms, us or ns), an ISO 8601 date, an RFC 2822 date, or now, today,
              yesterday or tomorrow, then any offsets like +90m, -3d or +1h30m. Spaces don't need quoting.

FLAGS
  -c, --copy             Also copy the --format value (iso by default) to the clipboard
  -f, --format=<option>  Print only this value
                         <options: iso|iso-local|local|epoch|ms|relative>
      --tz=<value>       IANA time zone to show local times in and read inputs without an offset in, like Europe/London
                         or UTC [default: the system zone]
      --unit=<option>    Unit of an epoch number, instead of guessing from its digit count (up to 11 is s, 12-14 ms,
                         15-17 us, 18-19 ns)
                         <options: s|ms|us|ns>

DESCRIPTION
  Show a date in every common format.

  With no input, it shows the current time:

  iso        ISO 8601 in UTC
  iso-local  ISO 8601 with the local (or --tz) offset
  local      The full local (or --tz) date and time
  epoch      Seconds since the Unix epoch
  ms         Milliseconds since the Unix epoch
  relative   From now, like "3d 2h ago" or "in 1h 30m"

  Those names are what --format takes to print just that value.

  Input can be an epoch number, an ISO 8601 date, an RFC 2822 date (like the ones in HTTP headers and emails), or now,
  today, yesterday or tomorrow. Dates with spaces don't need quoting.

  Epoch numbers are read by their digit count: up to 11 is seconds, 12-14 milliseconds, 15-17 microseconds and 18-19
  nanoseconds. Decimals are read as seconds. --unit overrides the guess, and anything finer than a millisecond is
  dropped.

  ISO dates without an offset are read in the local time zone, or in --tz, so --tz UTC reads them as UTC.

  Offsets after the date move it. Units are y, mo, w, d, h, m, s and ms, and can be combined, like +1h30m. Days and
  longer keep the same wall-clock time across daylight saving changes.

EXAMPLES
  Show the current time in every format

    $ swiss date

  Convert an epoch timestamp

    $ swiss date 1761300000

  Show a UTC time in another time zone

    $ swiss date 2025-10-24T10:00:00Z --tz Asia/Tokyo

  Copy the ISO timestamp for 90 minutes from now

    $ swiss date now +90m --format iso --copy

  Show midnight a week ago

    $ swiss date today -1w

  Convert a date from an HTTP header

    $ swiss date Fri, 24 Oct 2025 10:00:00 GMT
```

## `swiss org branches`

Delete local branches that have been merged into the default branch, removing the worktrees they're checked out in.

```
USAGE
  $ swiss org branches [-c <value>] [--gone] [-p | --dry-run | -y] [--unstarted]

FLAGS
  -c, --concurrency=<value>  [default: 8] Number of repos to fetch and check at once
  -p, --pick                 Pick the branches to delete from a list, including ones only deleted with --gone or
                             --unstarted
  -y, --yes                  Delete without asking first

      --gone                 Also delete branches whose upstream was deleted, even if they don't look merged
      --unstarted            Also delete branches that were never committed to, along with their worktrees

DESCRIPTION

  Every cloned repo in the org is fetched with --prune, which only updates origin/* refs. What it finds is listed, and

  - Merged means the default branch on origin contains the branch, or contains its changes as different commits, so
  squash and rebase merges count. A branch that got more commits after being squash-merged doesn't.
  - A branch whose upstream was deleted but that doesn't look merged is listed as kept, and only deleted with --gone.

  there are no uncommitted or untracked files and the default branch isn't checked out in another worktree. Otherwise
  it's listed as kept, as is a branch that's only gone upstream.

  as upstream) are listed as kept, since they're usually ones you just created or scaffolded a worktree for. They're
  only deleted with --unstarted.

  repo to pick from instead of confirming them all. Merged branches start picked, as do gone and unstarted ones when
  --gone or --unstarted is passed.

  Uses the same "org" settings as `org sync`; see `swiss org sync --help`.

  Also delete unmerged branches whose upstream is gone, without asking

    $ swiss org branches --gone --yes

    $ swiss org branches --pick
```
